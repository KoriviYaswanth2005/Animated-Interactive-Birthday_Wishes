## ✨ About The Project

**Kokku** is a premium interactive birthday wishes website designed as a personalized digital birthday experience.

It combines beautiful photographs, smooth animations, interactive birthday wishes, countdown effects, animated backgrounds and responsive design into one memorable celebration experience.

## 🎉 Birthday Wishes

- 💌 Personalized birthday messages
- 🎂 Birthday countdown
- 🎞️ Interactive photo carousel

- 🎨 Multiple visual themes
